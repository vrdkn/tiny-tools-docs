## Описание

Этот проект создан в рамках учебного задания по документированию программных продуктов.  
Он содержит простой скрипт для обработки текстовых данных (поиск ключевых слов).

Основные возможности:
- Подсчёт частоты слов в текстовом файле
- Поиск заданного слова и вывод количества вхождений
- Поддержка командной строки

## Требования

- Python 3.10 или выше
- Операционная система: Windows, macOS, Linux

## Установка

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/vrdkn/tiny-tools-docs.git
cd tiny-tools-docs

# 2. Создайте виртуальное окружение
python -m venv venv
source venv/bin/activate   # Для Windows: venv\Scripts\activate

# 3. Установите зависимости
pip install -r requirements.txt
